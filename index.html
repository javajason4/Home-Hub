iPad Setup & Hosting Guide

📲 Add to iPad Home Screen

  1. Open this site in Safari on your iPad.
  2. Tap the Share button (square with up arrow).
  3. Scroll down and tap "Add to Home Screen".
  4. It will now launch as a clean, full-screen app!

🌐 Free Hosting Options

You can host this single file easily on:

  • GitHub Pages: Upload index.html to a repo and turn on Pages in settings.
  • Netlify / Vercel: Drag and drop the folder containing this file into their dashboard for instant URL generation.
